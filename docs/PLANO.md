# Plano del proyecto

**Lectura Rápida** es una app web instalable que entrena la atención, la lectura activa, la velocidad flexible y la retención. Sirve para leer cualquier material: estudio, investigación, libros, trazados y proyectos de instrucción. Todo se basa en evidencia y se mide con datos propios.

## Fases

| Fase | Contenido | Criterio de salida | Estado |
| :--- | :--- | :--- | :--- |
| 0 — Plano | Diseño, plan, documentos, README | Diseño aprobado y plan en el repositorio | En curso |
| 1 — Esqueleto y medición | PWA, almacenamiento, lector de texto pegado, ppm, cuestionario, sondeos, diagnóstico | Diagnóstico completo sin conexión, con ppm, comprensión y divagación | Pendiente |
| 2 — Formatos y lectura activa | PDF, EPUB, web, libro físico, subrayado, notas, glosario, marcapasos | Se lee y anota un PDF, un EPUB, un artículo web y un libro físico | Pendiente |
| 3 — Programa y retención | 28 lecciones, fichas con FSRS, recuerdo libre, re-test a 24 h, atención, 12 textos | Días 1-7 completables de principio a fin | Pendiente |
| 4 — Cuaderno, proyectos y progreso | Fuentes, proyectos de escritura, exportación a .docx y Markdown, gráficas, respaldo | Trazado de ejemplo exportado a .docx | Pendiente |
| 5 — Pulido y publicación | Accesibilidad, rendimiento, GitHub Pages | App instalable desde la URL pública | Pendiente |
| 6 — Validación | Uso real durante 28 días y ajustes | Informe con resultados | Pendiente |

Cada fase tiene su propio plan en `docs/superpowers/plans/`, escrito cuando la fase empieza.
